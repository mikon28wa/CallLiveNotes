# Backend (Nicht mehr benötigt)

**Wichtig:** Dieses Backend wird in der aktuellen Version von CallLiveNotes **nicht mehr benötigt**.

Die aktuelle Version (ab Juni 2026) ist eine vollständig offline fähige mobile App, die alle Daten lokal auf dem Gerät in einer SQLite-Datenbank speichert.

## Migration
Falls Sie die alte Version mit MongoDB-Backend verwendet haben:
1. Exportieren Sie Ihre Daten aus der alten Version
2. Installieren Sie die neue Offline-Version
3. Importieren Sie die Daten über die Backup-Funktion
